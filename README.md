# AtTheMoment
<img src="icon.png" width="150" />


## Developers
- Riccardo Silvestri

AtTheMoment is an application developed in SwiftUI that provides detailed information about public transport and related bus stops in the city of Milan. The application aims to create a minimal interface with features related to the display of timetables, offering an intuitive and interactive user experience.

## Main features

- **Vehicle list**: displays a list of public transport vehicles divided by type (bus, tram, train).
- **Stop list**: displays a list of stops divided by direction (outward and return).
- **Stop information**: displays details such as the street, waiting time and location of the stop on an interactive map via AppleMap.

The project for the SwiftUI version is just an experiment to convert some features, it does not aim to become an official release and does not have all the features present on the Android version, you can still use it for personal use by importing the IPA file on your Iphone device
